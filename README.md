# Yoru 夜 — Trading Diary

Elegant dark Japanese-inspired diary for traders.

## Features
- Daily Activities logging
- Full Trading section (pair, side, P&L, emotion, notes)
- Problems space
- Solutions & Reference space
- Mood tags (雨 桜 星 月 雪 灯)
- 5 anime-inspired night wallpapers
- Archive of past entries
- Everything saved privately in your browser

## Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) → Add New Project
2. Import this repository (`adehanloye231-cpu/dairy`)
3. Click **Deploy** (no build settings needed)

Your diary will be live in seconds.
